# src/data/dataset/utils — データセット生成ヘルパ

HDF5 データセット組み立て時に使う低レベルヘルパ。系列内の動作開始位置の特定と、
試行ごとの CSV DataFrame を固定長 NumPy 配列に変換する処理を担う。

## ファイル

| ファイル | 役割 |
|---|---|
| `detect_movement_onset.py` | 速度/時間ウィンドウから動作開始フレームを検出し、実際の動作区間に系列を切り出す。 |
| `dataframe_to_numpy.py` | 試行 CSV を読み込んで NumPy 配列に変換し、系列長を調整（パディング/切り出し）してデータ長を揃える。 |
